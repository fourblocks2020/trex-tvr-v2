# TVR intent venue 생략과 core SOR 호환

## Criterion

TVR의 NXT-only eligible slot과 KRX main eligible slot에서 생성되는 모든 buy/sell strategy intent는 `venue` field를 보내지 않아야 한다. core #61은 omitted venue를 SOR original order venue로 정규화해야 하며 TVR은 wall-clock session을 근거로 KRX, NXT 또는 SOR를 명시해서는 안 된다.

## Verification

- 성공 조건: buy/sell payload 모두에 `venue` key가 없고 wire parser/client가 이 payload를 전달하며 core omitted venue→SOR contract와 호환된다.
- 실패 조건: TVR이 session 또는 markets에 따라 venue를 채우거나, omitted venue가 serialization/admission에서 거부되거나, TVR이 core actual venue를 추정하면 FAIL이다.
- 현재 평가: current local implementation과 직접 buy/sell assertions로 satisfied됐다.
- 검사 방법: `tests/runtime/test_intent_builder.py`, `tests/runtime/test_daemon_cycle.py`, `tests/test_transport_wire.py` 및 runtime source의 venue serialization search를 실행한다.
