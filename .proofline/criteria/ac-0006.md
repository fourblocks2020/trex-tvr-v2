# Python 3.12와 잠긴 package build

## Criterion

OCI image는 Python 3.12를 canonical runtime으로 사용하고 repository-owned `uv.lock`과 exact build backend에서 TVR package를 non-editable로 설치해야 한다. Build에 사용한 uv·Python input과 target platform은 immutable하게 고정되고 build-only backend는 runtime environment에 남지 않아야 한다.

## Verification

- 성공 조건: `uv lock --check`가 통과하고 lock에 runtime dependency와 `setuptools==80.9.0` build extra가 포함된다. Docker build는 digest-pinned uv/Python, `linux/amd64`, locked build extra와 `--no-build-isolation`을 사용한다.
- 성공 조건: runtime에서 `trex_tvr.__version__` import와 두 CLI help가 동작하며 `setuptools`가 발견되지 않는다.
- 실패 조건: unpinned build backend, mutable uv/Python base input, editable source mount, source tree에서만 가능한 import 또는 runtime setuptools 잔존이 있으면 FAIL이다.
- 현재 평가: implementation commit에서 lock은 19 packages로 검증됐고 pinned Docker build, installed import/CLI, runtime setuptools 부재가 실제 PASS하여 satisfied다.
- 검사 방법: `uv lock --check`, release contract tests, `docker build --platform linux/amd64`, networkless installed import/CLI와 `importlib.util.find_spec('setuptools')`를 실행한다.
