# Typed RabbitMQ 연결 profile과 중복 설정 차단

## Criterion

TVR은 heartbeat `30`, blocked connection timeout `30`, socket timeout `10`초를 typed configuration 기본값으로 소유하고 각 값을 1 이상의 정수로 startup에서 검증해야 한다. RabbitMQ URL query에 `heartbeat`, `blocked_connection_timeout`, `socket_timeout` 중 하나라도 존재하면 application-owned 설정과 중복되므로 credential을 노출하지 않고 startup을 실패시켜야 한다.

## Verification

- 성공 조건: 기본값과 유효 override가 Pika `URLParameters`에 적용되고 세 URL tuning key 각각의 중복이 `ConfigError`로 거부된다.
- 실패·경계 조건: 0·음수·정수가 아닌 값 및 URL 중복은 connection 생성 전에 실패하며 오류에는 URL credential이 포함되지 않는다.
- 검사 방법: `tests/test_transport_resilience.py`의 config/profile 및 secret masking test와 `config/instance.example.toml` read-back을 실행한다.
