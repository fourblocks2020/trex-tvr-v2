# Slot 및 intent RPC publisher confirm 의미 경계

## Criterion

Slot RPC와 intent admission RPC의 공용 request publish 경로는 RabbitMQ publisher confirm을 사용해야 한다. Nack 또는 publish/reply AMQP failure는 transport unavailable로 분류하되 confirm 성공을 core admission, 주문 생성, execution 또는 fill 완료로 표현해서는 안 된다.

## Verification

- 성공 조건: Connection channel에서 confirm mode가 활성화되고 Slot/intent 공용 `rpc_call()`의 실제 RabbitMQ direct reply-to round-trip이 성공한다.
- 실패·경계 조건: Pika `NackError` 및 AMQP stream failure는 `TransportUnavailableError`로 변환되고 direct-reply consumer가 정리된다. Confirm만으로 core admission status를 만들지 않는다.
- 검사 방법: `tests/test_transport_resilience.py`, `tests/test_transport_resilience_rabbitmq_integration.py` 및 README 의미 경계를 검사한다.
