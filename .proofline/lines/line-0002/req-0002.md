# TVR requester-versioned GHCR 이미지 게시 계약

## Objective

`trex-tvr-v1`이 Python 3.12와 잠긴 dependency에서 재현 가능한 non-root/read-only OCI image를 만들고, requester가 별도로 승인해 생성한 strict stable SemVer tag에서만 exact tested artifact를 GHCR에 게시할 수 있게 한다. Branch/main 검증과 registry write를 분리하고 source·version·image·archive·registry digest provenance를 fail-closed로 연결하며 publication smoke의 보장과 production readiness·rollout의 경계를 명확히 한다.

## Scope

- Python 3.12, repository-owned `uv.lock`, exact build backend와 locked non-editable package installation을 사용한다.
- uv·Python·RabbitMQ·Redis image 입력과 `linux/amd64` platform을 고정한다.
- `vX.Y.Z` stable tag push만 publication 후보가 되고 branch/main/PR/manual verification에는 registry write 권한·login·push 경로가 없어야 한다.
- GitHub event/ref, exact checkout, Git tag, `pyproject.toml`, `trex_tvr.__version__`, OCI version을 registry login 전에 검증한다.
- verify job에서 source image를 한 번 build하고 installed payload, secret exclusion, dependency startup와 initial status까지 smoke한 exact image를 archive·checksum·image ID와 함께 publish job으로 전달한다.
- publish job은 rebuild하지 않고 archive checksum, loaded image ID, OCI revision/version을 재검증한 뒤 SHA12와 version selector를 push하며 두 selector의 registry digest가 동일한지 확인한다.
- `latest`를 만들지 않고 immutable digest를 publication evidence와 운영 기준으로 사용한다.
- Runtime은 user `10001:10001`, read-only root filesystem, dropped capabilities, no-new-privileges와 config·secret·status mount 분리를 사용한다.
- Isolated smoke는 RabbitMQ AMQP login, Redis ping, fake kis-data-hub `/health`, TVR `build_daemon()`과 initial `started` status snapshot까지만 검증한다.
- 운영 문서는 immutable digest rollout·rollback, 기존 tag 비재생, bounded stop, status snapshot 및 외부 state 비rollback을 설명한다.
- GitHub의 구현 진행·완료 comment를 정식 ProofLine lifecycle artifact가 아닌 repository-local evidence snapshot으로 보존한다.

## Constraints

- GitHub issue #8의 APPROVED 본문과 승인 comment가 scope authority다.
- Python/package/runtime canonical version은 현재 `0.1.0`이며 실제 release tag version과 exact match해야 한다.
- Real credential을 build context, image, archive, metadata 또는 helper output에 넣지 않는다. Evidence에서는 필요한 값을 `[REDACTED]`로 표현한다.
- Source archive publication은 exact commit `7b3750781f27f53fa4a35122e49d8fe45b486ffe`의 구현을 기준으로 평가하지만 AC는 특정 release tag 게시 완료를 요구하지 않는 version-independent contract를 소유한다.
- Normative Design Documents: 없음. 이 REQ와 AC-0006~AC-0011이 normative specification을 소유한다.
